# Upstream commits: 2025-09

All 29 upstream commits are from **2025-09-22**, by kikki (WAABE), publishing a proof of concept built
over about 21 days on a 30-day Navisworks Manage 2026 trial (from the upstream README). None links an
issue.

Upstream's own findings (README): read operations were easy, write operations harder and crash-prone;
40% of the time went to researching the API and COM examples. It was "not to create a stable product,
but to explore technical possibilities". The fork starts from `43c5483` ([2026-10](2026-10.md)).
